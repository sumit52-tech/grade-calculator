# Grade Calculator 🎓

A simple **Student Grade Calculator built with Python** that calculates a student's total marks, percentage, and grade based on marks entered for multiple subjects.

## Features
- Enter marks for different subjects
- Calculate total marks
- Calculate percentage
- Automatically determine the grade
- Simple and beginner-friendly Python code
- Uses basic Python concepts such as loops, conditions, and input/output

## Technologies Used
- **Python 🐍**

## Purpose
This project is created for beginners who are learning Python programming and want to practice basic concepts like variables, loops, conditional statements, and user input.

## Example
The program takes the student's marks as input and displays the **total marks, percentage, and final grade**.
